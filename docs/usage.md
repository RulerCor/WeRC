# WeRC v1.2.1 使用说明

WeRC 是 Windows 微信收发平台，也提供独立的聊天资料工具。电脑微信需要保持登录。原生收发支持微信 4.2.0.52（推荐）、4.1.15.13 和 4.1.13.7 的匹配 x64 构建。

## 第一次使用

请自行下载并安装微信，打开并登录后再连接 WeRC。支持情况以软件检测到的微信实际构建为准。

1. 首次进入自动打开全屏设置。先打开并登录电脑微信，确认检测结果，点击“已登录，自动连接”；软件自动登记、绑定、核验身份并准备聊天资料。
2. 有多个安装或进程时选择一次；未适配版本会明确提示。后台来源占用时，首次设置自动等待约 30 秒，可取消；资料准备失败可重试，也可暂不读取历史。无需退出微信、导入全库或填写密码。
3. 需要 Bot 时点击“启动并授权 Bot 收发”，再复制配置到客户端，勾选已保存后继续。也可暂不接 Bot；端口和只读权限在折叠选项内。
4. 完成后进入会话。“微信会话”浏览当前电脑已有资料，“实时新消息”查看连接期间保存的消息，“离线归档”回看导入的快照。独立工具仍在“工具与诊断”中。
5. 未完成的设置会保留所在步骤，下次进入可继续；完成后不再自动弹出。下次启动会尝试恢复已确认的微信连接和已开启的 API；需微信保持登录，多个进程时需选择。手动断开或停止服务会保留停用选择，不重新生成令牌或提交旧任务。可在“设置 → 重新运行首次设置”或“连接 → 自动设置微信”再次打开。右上角使用指南只作简短帮助。

连接不需要先导入全部聊天历史。软件自动检测本机微信和组件。

## Bot 接入与结果

默认回环地址为 `http://127.0.0.1:5031`，端口可设置为 1024–65535。启动服务后授权“Bot 收发”，一次取得当前账号的常用收发与媒体权限。签发时可选择有效期（Bot 默认 90 天，其他用途默认 7 天），可自定义到秒，也可选永久。已有令牌的有效期与权限保持不变。

Bot 可直接提交已授权请求，无需逐条回桌面批准。白黑名单、免打扰、是否回复、模型和业务定时由 Bot 客户端决定；平台转发授权账号全部可观测消息与真实结果。朋友圈发布另需相应授权，不包含在默认 Bot 收发预设中。

复制“Bot 连接配置”用于通用客户端；复制“MCP 配置”用于支持 Streamable HTTP 的客户端；仅支持 STDIO 的客户端可使用随包附带的 `werc-mcp-stdio` 转接器。复制的 STDIO 配置会使用当前安装目录中的程序位置，移动程序后重新复制配置；配置通过环境变量传入当前 HTTP 地址和令牌，不需 Node 或 Python。令牌只显示一次，勿分享连接配置。

消息流与产品事件流分别保存游标。发送重试复用同一幂等键，结果未知只回查，不重新发送。服务端接受、本机记录已写入、接收端已确认分别记录。普通文字、图片、语音、附件、视频、表情、引用和成员提醒可通过任务编号回查。

接口、权限、媒体上传、MCP 工具与续传示例见 [Bot 接入说明](bot-client.md)；接口字段以随包的 `openapi.json` 为准。退出 WeRC 停止服务，隐藏窗口不停止。

## 查看历史和资料

在“微信会话”点击“打开在线会话”，软件自动准备来源。会话、跨会话搜索、联系人、朋友圈、微信收藏、专项记录与文件传输助手按分类展示；切换分类会关闭临时会话。

打开聊天后可按日期、关键词、消息类型、发送者或服务器编号查找，查看前后文、日历和媒体。右键或 Shift+F10 打开消息操作。长消息完整内容保留在详情中。来源窗口约两分钟过期，过期后重新读取；多消息分片逐个读取，不代表同一时刻的原子快照。

联系人按昵称、备注、微信号和精确账号搜索。头像、简介、群昵称、群主与置顶来自本机缓存；缺失会保留未知，不等同于服务器实时完整好友关系。群资料与置顶默认折叠；已识别的置顶可按完整服务器编号找原消息，未知置顶缓存与明确空列表分别显示。

朋友圈可按需读取本页作者备注与昵称；“与我有关的互动”逐页列出他人对我的动态的赞、评论和明确回复我的评论。它只使用准确账号，不根据正文中的昵称或@符号猜人，也不等同完整服务端通知。

专项记录包括好友验证、搜索、撤回、转账和红包等可读取的本机记录。聊天中显示通话、系统、位置、名片、小程序、音乐、交易等相应卡片。原始交易或好友状态码尚未可靠适配的部分只显示来源字段，不猜测到账、退还、过期或好友关系，也不会操作资金或接受申请。

## 手动发送

在当前聊天中或“发送队列 → 新建消息”选择收件人、填写内容并保存预览，核对后批准一次。媒体和朋友圈入口按层级收纳。离开会话不会删除已保存草稿；任务记录可继续查看与回查。

群成员提醒从已读取的群成员页选择，支持 1–8 个已识别成员；不支持昵称猜测或 @所有人。引用需要选择认证会话里的原消息。收到原生回调不会直接变为“接收端已收到”。

发送预览中的“发送时间”默认立即发送。稍后发送受草稿和收件人有效期共同约束，界面显示实际可选期限；到点时 WeRC、原连接与附件必须有效。休眠、退出或过期时不会无限补发，重启和重连不自动续期旧批准。Bot 的长期业务调度放在客户端。

## 媒体、转写与离线归档

图片、语音、视频、表情与文件按需读取，不自动播放。成功保存的内容加密落库，可以回读、另存和清理；不能取得的资源单独显示原因。媒体格式和大小限制以能力页和相应问号说明为准。

在资料库中查看本机收藏、转写稿、聊天归档与计划。归档可逐项补齐媒体，暂停或重开后继续；转写复用已安装模型，允许校对和导出 TXT/SRT/JSON。聊天海报、年度/双人报告、联系人时间线及聊天与已保存朋友圈的关联报告使用所选资料范围；缺少身份或来源时不会推断完整历史。

导出入口默认折叠。支持相应工具的 JSON、JSONL、CSV、TXT、HTML、Markdown、SQL、XLSX，以及 ChatLab、WeClone 和离线媒体 ZIP；不同工具支持的格式分别列出。可以筛选范围、会话、媒体和列。只导出已保存或成功补齐的媒体，缺失逐项报告。

默认保存位置使用本机系统下载目录，也可调用系统保存对话框。聊天资料导出默认在同名文件后加序号保留副本；高级选项可选择同内容逐字节比较后跳过，或在明确确认后替换所选文件。其他工具默认拒绝覆盖。离线 ZIP 使用相对资源路径，解压后可移动阅读；ZIP 本身不加密。跨电脑迁移敏感资料使用密码保护的备份和导入。导出期间资料版本变化会拒绝混用，取消或失败不会发布部分文件。

归档内的文字、时间、类型修改及删除/恢复只影响本机副本，保留原文与变更记录，不写微信源数据库，也不发送消息。副本导出明确标注本地变更。

## 设置与维护

“设置”收纳主题、动画、托盘与通知、应用锁、存储迁移、缓存、诊断及应用更新。应用密码默认关闭，仅在用户主动设置应用锁后启用；首次使用无需设置密码。密码/恢复码与 Windows Hello 分别按本机可用性提供。缓存工具区分可重建缓存与账号、密钥、消息、媒体等受保护资料。

v1.2.1 采用手动更新：退出 WeRC，安装新版本或替换程序目录。账号与资料默认保存在当前 Windows 用户的本地应用资料目录，程序与资料分开。更新前可以使用加密备份；不要删除资料目录。签名自动更新暂不提供。

高级连接设置中的手动取钥可选择1—30秒扫描上限，查看实际读取字节、事件序号和已用时间，随时取消。扫描字节不是完成百分比；取消不清除已有已验证密钥，已经提交的成功结果会保留。

移除本机配置前需要停用导出/公众号计划，并完成或取消待处理任务。移除成功会关闭对应原生连接、清理本机配置并撤销令牌，不操作微信数据目录。

## 安装、兼容与离线使用

适用于 Windows 10 1903 及以上 / Windows 11 x64。安装版附带离线 WebView2 安装器，按向导安装即可；便携版解压整个目录再运行 werc-desktop.exe，缺少 WebView2 Runtime 时先运行附带的 WebView2RuntimeInstaller.exe。不要只复制单个 EXE。已附带应用所需的 C++ 运行库，无需 Node、Python、Rust 或开发工具。

程序支持相对位置加载组件，允许放在含中文或空格的路径中。资料默认留在当前用户本地应用资料目录；可在设置中迁移。需要单独的资料配置时，可以用 `werc-desktop.exe --data-directory "资料目录"` 启动，相对路径以启动工作目录为准。同一个资料配置只能启动一个进程。

完整版附带 Whisper tiny 和 sherpa CPU 运行时，基础多语言离线转写无需另行下载。Paraformer 等其他权重可从已取得使用许可的本地目录导入。NVIDIA CUDA 是可选项：在设置中手动开启、检测本机，再确认下载匹配组件；AMD、Intel 和不符合条件的 NVIDIA 使用 CPU。CUDA 不保证提速；内置 Whisper 为 CPU，自动 CUDA 路径用于 sherpa。识别时不上传音频。

连接时自动核对实际加载的微信核心文件，并显示当前构建可用的功能。4.1.15.9 可识别适配档案，未开放原生收发。兼容与使用限制见 [版本说明](release-notes.md)。
