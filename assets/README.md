# 图标 / App icons

公开源码保留发行版所用的 WeRC 图标。原始参考图未放入仓库，图标画面不因源码公开而获得额外许可。 / This repository includes the icon assets used in published builds. The original reference image is excluded; the artwork is not relicensed by publication of this repository.

`app-icon.png` 用于生成 Windows 和 Tauri 图标；执行 `npm run icons:generate` 可重新生成各尺寸。 / Run `npm run icons:generate` to regenerate platform icons from `app-icon.png`.
